

 # 🐍 Object-Oriented Programming (OOPs) Concepts in Python

This repository contains examples and explanations of **Object-Oriented Programming (OOPs)** concepts implemented using **Python**.  
It is designed to help beginners and intermediate learners understand how OOP works in Python through simple, practical examples.

---

## 📘 About the Repository

Object-Oriented Programming (OOP) is a fundamental programming paradigm based on the concept of “objects” that contain both data and behavior.  
In this repository, you’ll find Python programs that demonstrate all major OOP concepts with clear code and explanations.

---

## 🧩 Topics Covered

### 🔹 1. Class and Object
- Defining classes and creating objects
- Understanding the `__init__` constructor
- Accessing class attributes and methods

### 🔹 2. Inheritance
- Single Inheritance
- Multiple Inheritance
- Multilevel Inheritance
- Method Overriding and `super()` function

### 🔹 3. Encapsulation
- Public, Protected, and Private Members
- Getter and Setter Methods

### 🔹 4. Polymorphism
- Method Overloading (via default arguments)
- Method Overriding
- Operator Overloading (`__add__`, `__str__`, etc.)

### 🔹 5. Abstraction
- Abstract Classes and Methods using the `abc` module
- Achieving abstraction using interfaces

---

## 🧠 Learning Objectives

By going through this repository, you will:
- Understand the core principles of OOPs in Python.
- Learn to design reusable and modular code.
- Be able to apply OOP concepts in real-world projects.
